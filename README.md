# ⚡ Mohit Singh Chahar - Personal Portfolio

A modern, high-performance developer portfolio built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, and **Framer Motion**. Featuring a sleek dark aesthetic, dynamic animations, interactive skill marquees, and responsive design.

---

## ✨ Features

- 🚀 **Modern Tech Stack**: Next.js 16 (App Router), React 19, TypeScript
- 🎨 **Sleek Dark Cyber Aesthetics**: Custom cursor spotlight, glowing electric borders, glitch text effects, and smooth micro-animations
- 💻 **Interactive Sections**:
  - **Hero**: Dynamic typewriter effect, glitch heading, and interactive avatar
  - **Skills**: Categorized multi-directional marquee with electric border accents
  - **Projects**: Interactive showcase featuring live demos, github links, and tech badges
  - **Timeline**: Education and experience roadmap
  - **Contact & Footer**: Direct reach-out form and social links
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- ⚡ **SEO & Performance**: Optimized asset delivery, metadata, and fast static generation

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or later
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Scripts

- `npm run dev` - Start development server with Turbopack
- `npm run build` - Create an optimized production build
- `npm run start` - Run the production build locally
- `npm run lint` - Run ESLint checks
